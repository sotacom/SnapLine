Crafted for Speed & Tactility

Lightweight mechanics with unmistakable physical warmth.

01 · Choreography

4-Stage New Capture Physics

When a screenshot saves, the line lowers gently with a light breeze, older Polaroids slide left along the curve, and the new shot arcs up from the bottom-right until the wooden pin snaps shut—sending an elastic ripple down the rope.

02 · Performance

120fps & 0% Idle CPU

Demand-driven CADisplayLink freezes automatically once pendulums settle. Virtualized layer pooling keeps memory tiny even with 2,000+ screenshots.

03 · Workflow

Drag, Quick Look & Video

Drag Polaroids straight into Slack, Figma, or Finder. Single-click for Quick Look, or hover any .mov / .mp4 screen recording for an instant inline loop.

04 · Precision

1:1 Trackpad Timeline

Chronologically sorted oldest-left to newest-right. Native Trackpad momentum, zero implicit animation ghosting, and ahead-of-scroll thumbnail prefetching.

05 · Custom Folder

Custom Location & Instant Mode

Auto-reads your macOS screenshot folder or lets you pick any directory with optional system sync—plus a 1-click toggle to bypass macOS’s 5s thumbnail delay.

06 · Privacy First

100% Local. Zero Telemetry. Zero Cloud.

Your screenshots never leave your Mac. No analytics, no accounts, no network entitlements—just an open-source Swift binary (~1.1 MB) you can inspect and build yourself.

Get Started in 30 Seconds

Install on macOS 14+ (Apple Silicon)

1

Download & Drag

Grab SnapLine-1.0.0-macos-arm64.dmg from GitHub Releases and drag SnapLine.app into Applications.

Download .dmg (v1.0.0)
2

Clear Gatekeeper (Ad-hoc Signed)

Because this open-source build is ad-hoc signed rather than Apple-notarized, run once before launching:

xattr -cr /Applications/SnapLine.app
3

Or Build from Source (No Xcode)

Compile and sign directly using Apple Swift Command Line Tools:

git clone https://github.com/sotacom/SnapLine.git && cd SnapLine && ./scripts/build_app.sh
